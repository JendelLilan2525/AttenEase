# AttenEase

AttenEase is a simple attendance management system developed using Django.

## Features

- Home page
- About page
- Attendance recording
- Attendance records display
- Student records display
- Contact page
- Django admin panel
- Reusable navigation bar and footer
- Responsive design
- SQLite database

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Git
- GitHub

## How to Run the Project

1. Clone or download the project.
2. Open the project folder in VS Code.
3. Create and activate a virtual environment.
4. Install the required packages using: pip install -r requirements.txt
5. Run the database migrations using: python manage.py migrate
6. Start the server using: python manage.py runserver
7. Open http://127.0.0.1:8000/ in your browser.
